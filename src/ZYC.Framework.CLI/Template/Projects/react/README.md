# __PROJECT_NAME__

A ZYC.Framework host project whose tab UI is a React app (Vite + TypeScript) running in WebView2.

## Requirements

- .NET 10 SDK
- Node.js 20.19+ or 22.12+ (required by Vite)
- Microsoft Edge WebView2 Runtime

## Layout

| Path | Purpose |
|------|---------|
| `Module.cs` | Registers the view as a tab. |
| `UI/__PROJECT_SHORT_NAME__View.cs` | WebView2 host. Serves the built React app from `https://__PROJECT_WEB_NAME__.example/` and answers the page's calls through `WebBridge`. |
| `Services/IGreetingService.cs` | Sample `[ExposeToWeb]` service the page calls. It is also exposed to MCP. |
| `ClientApp/` | React front end. `src/webview.ts` provides typed calls to the host; `src/host-services.d.ts` is generated by the build. |

## Build and run

Build and start the project as usual. The build runs `npm install` (when `package.json` changes) and `npm run build` (when front-end files change) in `ClientApp`, then copies `ClientApp/dist` to the `ClientApp` folder in the output directory.

Pass `-p:SkipClientAppBuild=true` to skip the front-end build.

## Hot reload while developing

```bash
cd ClientApp
npm run dev
```

Then start a Debug build of the app. While the Vite dev server is running on `http://localhost:5173`, the view loads it instead of the built files, so changes to `ClientApp/src` appear immediately. Release builds always use the built files.

## Talking to the host

The page calls C# services with types:

```ts
const greeting = await hostService('GreetingService').greetAsync('React')
```

To add a service:

1. Declare an interface marked with `[ExposeToWeb]` (see `Services/IGreetingService.cs`) and register its implementation, for example with `[RegisterSingleInstanceAs(typeof(IMyService))]`. The same interface can also carry `[ExposeToMCP]`.
2. Build. The build runs `ZYC.Framework.CLI.exe web-types` on this assembly and regenerates `ClientApp/src/host-services.d.ts`, which gives `hostService('MyService')` its types. Method and property names are camelCase, enums are strings, and every call returns a `Promise`.

`UI/__PROJECT_SHORT_NAME__View.cs` passes messages to `WebBridge` only when they come from the page it loaded, so other sites never reach the services. Overloaded methods are not supported, and a `CancellationToken` parameter is left out of the TypeScript signature.
